# Claude Code plugins

Small Claude Code plugins I built for my own workflow and figured others might want too.

## Install

```
/plugin marketplace add DeanPhillipsOKC/claude-plugins
/plugin install usage-peaks@dean-plugins
```

## Plugins

| Plugin | What it does |
| --- | --- |
| [usage-peaks](plugins/usage-peaks) | Live 5-hour plan usage in the status line, the peak of every 5-hour window, and a graph of usage over time |

## Support

These are provided as-is under the MIT license. Each plugin's README says which Claude Code version it was tested on. Some use APIs that are still in early access, so a Claude Code update can break them. Bug reports are welcome, but I can't promise quick fixes.
